# 燼境設計
單機自動戰鬥生存遊戲，三回合、每回合十五波，每五波首領與工坊。
三個武器欄、披風及腿部各最多四孔；任意已開孔可裝主動、輔助或光環，不限制顏色。寶石本身仍保留種類、名稱及顏色。
目前連線模型沿用裝備 linked：前 linked 個孔屬於同一群，剩餘孔各自獨立。尚未實作任意分段連線。
群內每顆主動獨立施放，共享所有相容輔助。輔助即使無相容技能也可存放，但沒有戰鬥效果。光環占一孔、預設關閉、不接受輔助。每個種類與 ID 的寶石只能裝一次。
傳說武器第一孔保留固定專屬技能，其餘孔自由配置。
怪物寶石掉率一般 5%、首領 35%；裝備一般 3%、首領 80%，兩次獨立抽取。掉在死亡處，光柱及名稱提示，玩家走近拾取。升級只精煉持有技能或給通貨，Boss 選裝備或通貨；商店傳說抽獎保留。
重複主動精煉一級，重複輔助或光環轉為一顆匠魂石。掉落保留跨波，死亡重開清除。
連鎖輔助：支援 projectile 或 chain 標籤（例如火球、冰矛、連鎖閃電），+2 次跳躍，基礎命中傷害乘 0.9，後續每跳再乘 0.85。投射物先消耗穿透再連鎖，不回頭擊中同一目標；附近沒有新目標時結束。新星、旋風、光環不相容。
